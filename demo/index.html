    Keyboard shortcuts

    • 1–4 focus a station

    • C chat input
    • A approve · E request a fix · R reject (only while a draft awaits review)
    • ? this help · Esc close

    Shortcuts are off while you type in a field.

    What is simulated

    Pip is a scripted character. There are no real model calls, no connected accounts and no network requests. The weekly data is synthetic and bundled with the page.

    • Real in this demo: the state machine, progress saved in your browser, the rubric checks on the scripted drafts, the permission rules, export and reset.
    • Simulated: Pip's drafting, its questions, and any "proof". It shows how a teach, review, fix, rerun, delegate loop could work, not how well a real AI does it.
    • Nothing is ever sent anywhere.
