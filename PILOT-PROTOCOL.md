# Manual pilot protocol (5 non-technical participants)
Status: **protocol and empty template only. No participants have been contacted and no results exist.** Automated tests are not usability validation.

Per participant (one 45–60 min session; the facilitator observes and does not drive):
1. Record start time. Prerequisites: Node installed? Claude Code installed and signed in? Note where help was needed.
2. Unzip → START → office opens. Record time-to-first-use (minutes to the first real result).
3. Checklist: created agent · added notes · sent task · answered clarification · gave feedback · edited rule · reviewed 2nd different case · granted bounded repeat · saw a scheduled result (may come later).
4. Count interventions (facilitator hints/fixes), each with a one-word reason.
5. Day 3–7: did they return on their own (yes/no)?
6. Ask them to download the milestone export; the participant decides whether to share it. Do not request task text.

Record in `pilot-results-template.csv`; take real-vs-stub provenance from the export. Leave unknown cells empty; never invent observations.
